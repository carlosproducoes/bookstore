# Protótipo — E-commerce de Livros

Frontend acadêmico navegável em HTML5 + Tailwind CSS + jQuery, sem backend.

Abra `index.html` no navegador.

Os dados são mockados e compartilhados entre as telas via `localStorage`, permitindo demonstrar fluxos como compra, alteração de status, solicitação/autorização de troca e geração de cupom.
